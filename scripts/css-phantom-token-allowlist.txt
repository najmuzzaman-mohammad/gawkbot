# Phantom CSS design tokens that are knowingly deferred.
#
# A phantom token is `var(--x, <literal>)` (or bare `var(--x)`) where --x is
# declared in no stylesheet and set by no component. See
# scripts/check-css-phantom-tokens.sh for why that is a bug and how to fix it.
#
# This list is for sites that need a HUMAN DESIGN CALL, not for silencing the
# gate. A token supplied at runtime from JS is detected automatically and does
# not belong here. Mapping to the wrong token is worse than a known-bad
# literal, so a site with no defensible mapping is parked here instead of
# guessed at.
#
# Format: one entry per line, `<path> <token> <count>`. The count is the exact
# number of `var(--token)` occurrences allowed in that file — a new sibling
# fails the gate, and an entry whose site was fixed fails as stale. Comments
# start with #; blank lines ignored.

# rule and its keyframes are dead. Delete them, or wire the component that was
# meant to set --i.
web/src/styles/onboarding.css --i 1

# ─────────────────────────────────────────────────────────────────────────
# BASELINE: phantom tokens in component inline styles (web/src/**/*.tsx).
#
# Found when the gate was extended from stylesheets to components. An
# inline `style={{ background: "var(--x, #0a0a0a)" }}` is the identical
# bug in a place a CSS-only scan cannot see — WorkspaceRail pins its whole
# rail to #0a0a0a in every theme this way.
#
# FORWARD-ONLY, same contract as scripts/file-size-allowlist.txt: these
# entries may shrink or disappear, never grow, and a NEW phantom token in
# any component is a violation rather than a new line here. Each is owned
# by the team that owns the component; the fix is the same as for CSS —
# point at a token that exists in every theme.
#
# The baseline started at 24 entries. The theme-breaking ones have since
# been fixed (WorkspaceRail's five, SettingsApp's pale --accent-100
# background, SkillsApp's border, CommandRow's surface) along with the
# --danger family, which had a real token waiting in --red. What is left
# is deliberately left.
# ─────────────────────────────────────────────────────────────────────────
