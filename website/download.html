gawkbot Desktop

Your team of always-on onlookers in a native window, with no browser tab and no terminal. Same workspace as the CLI, and the same amount of finished work.

Download Pick your platform below

macOS YOU

Universal (Apple Silicon and Intel) · macOS 11+ · signed and notarized by Apple

Download .dmg
  1. Open the downloaded gawkbot-mac.dmg.
  2. Drag gawkbot into your Applications folder.
  3. Launch it from Applications or Spotlight. Your workspace opens in the app.
No scary warnings It is notarized by Apple, so it opens straight away, with no "unidentified developer" prompt.

Windows YOU

Windows 10/11 · 64-bit · WebView2 (built in to Windows)

Download installer
  1. Run the downloaded gawkbot-windows-setup.exe.
  2. Follow the installer, then launch gawkbot from the Start menu.
What you will see, and why The Windows app is not code-signed yet (signing is on the way), so Windows will warn you. That is expected, and it is safe:
  1. Your browser may flag the download as "not commonly downloaded" → choose Keep.
  2. Windows shows "Windows protected your PC" (SmartScreen) → click More info, then Run anyway.

View all releases & previous versions on GitHub →

Prefer the terminal? Or on Linux?

The desktop app and the CLI are the same workspace, so use whichever you like. The CLI runs everywhere, including Linux:

npx gawkbot@latest

A native Linux desktop build is on the roadmap; for now Linux runs via the CLI above (your workspace opens at localhost:7891).
